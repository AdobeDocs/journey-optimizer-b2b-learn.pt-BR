# Ouvir um nó de evento

Use o nó [!UICONTROL Escutar um evento] em [!DNL Adobe Journey Optimizer B2B Edition] para avançar uma jornada quando ocorrer um evento. Compare eventos de conta e de pessoa, defina critérios correspondentes e configure tempos limite para controlar a duração da espera da jornada.

>[!VIDEO](https://video.tv.adobe.com/v/3443219/?quality=12&learn=on)

## Ouvir os fundamentos do nó

O vídeo aborda estes tópicos:

* A diferença entre eventos de conta e eventos de pessoa.
* Critérios correspondentes para acionadores de evento.
* Configurações de tempo limite para eventos que não ocorrem no tempo especificado.

## Documentação relacionada

Para obter informações sobre eventos, etapas de configuração e opções de tempo limite com suporte, consulte [Ouvir um evento no guia do usuário](https://experienceleague.adobe.com/en/docs/journey-optimizer-b2b/user/journeys/journey-nodes/listen-for-event-nodes){target="_blank"}.
